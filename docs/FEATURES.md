# Windows Island 完整功能列表

本软件由 Snowflake006 基于 [Renly1994 / 岛仔 Daozai](https://github.com/Renly1994/xiaotang-daozai) 二次开发。致敬原创，保留 MIT 版权与许可。

## 桌面状态与布局

- 智能体状态：Codex / ChatGPT、DeepSeek Harness、豆包、WorkBuddy、Claude、Cursor、OpenClaw、Ollama、Gemini。按可用的本机日志 / 窗口状态显示在线、思考、工具执行、需要操作、完成、停止、异常或待确认。
- 完成反馈：后台工作时保留图标，完成后按设置短暂停留，新任务会取消旧完成提示。
- 详情：查看可读取的状态来源、输入 / 缓存 / 输出 Token、上下文与额度快照；点击切换相应客户端窗口。
- 紧凑状态栏：根据实际文字宽度占位，多个项目按需弹性展开；最多显示 1–6 个智能体图标，额外项目汇总显示。
- 空闲待办：没有需要显示的智能体时，轮播今日未完成任务；点击进入待办。
- 徽标：Windows 原版蓝色标识与中国传媒大学校徽二选一，可单独开关、独立拖动。
- 排列：徽标、智能体 / 待办、时钟、电量、吉祥物、AI 额度、音乐与专注可调整横向顺序；旧设置自动兼容。
- VPN：Clash Verge / Mihomo 本机状态和当前节点延迟；整个时间胶囊以蓝色（≤150ms）、橙色（151–300ms）、红色（更高或超时）显示，不添加独立圆点。
- 解锁：Windows 会话解锁触发岛内问候，可显示本机面容字形动画；支持开关和停留时长。

## 外观与系统交互

- 经典黑、奶油、毛玻璃浅色、毛玻璃深色、悬浮云五种皮肤。
- 刘海 / 胶囊两种形态；顶部、左侧与右侧停靠，鼠标靠近展开。
- 大小 80%–140%，位置偏移、多显示器选择、全屏隐藏、指定应用与浏览器自动避让。
- 极简模式、吉祥物表情与音乐动作、12 / 24 小时制、页面开关与排序。
- 系统电量与充电、音量、网络、蓝牙设备、大写锁定、输入语言提示。
- 托盘菜单、开机启动、本地数据目录入口、浅色 / 深色设置界面。

## 音乐与歌词

- Windows 媒体会话，播放 / 暂停、上一首 / 下一首、音量、播放进度和专辑封面。
- 网易云音乐、QQ 音乐、酷狗、汽水音乐兼容适配。
- 展开同步歌词、顶部收起时单行歌词、歌词时间偏移；无歌词时显示封面和歌名。

## 专注、饮水与任务

- 自定义专注 / 休息时长、番茄计时、收起状态的进度与剩余时间。
- 每日饮水目标、单次饮水量、记录与撤销、提醒时段和间隔，达到目标停止提醒。
- 添加、编辑与完成待办；单次提醒、每天重复、指定每周日期重复；到期自动恢复任务状态。

## 文件与剪贴板

- 拖入文件置物架、打开、定位、拖出到其他应用；移除记录不删除原文件。
- 最近 30 条文字剪贴板历史、固定常用条目、再次复制、跨重启保留；可关闭，不记录被密码管理器标记为敏感的内容。

## 通知与邮箱

- Windows 系统通知、微信 / QQ 未读提醒、微信多账号分别展示与窗口切换。
- 微信基于任务栏闪动提示，不读取聊天正文；可选托盘一键唤起。QQ 依赖系统通知权限。
- 多邮箱：QQ、163、126、腾讯企业邮、iCloud、Gmail、自定义 IMAP。
- 邮件列表、正文和全文窗口；网页链接交给默认浏览器。
- 自动识别并复制验证码，30 / 60 / 300 秒自动隐藏，通知正文预览可开关。
- 已读 / 未读、全部已读、删除到回收站与恢复；默认仅本地整理，可选择同步操作到邮箱。
- 识别正式邮件会议邀请，合并到日程并去重提醒。

## 日历与日程

- 月历、当日时间线、本地新增日程、ICS 文件导入、会议提前提醒。
- 飞书、钉钉、企业微信、iCloud、自定义 CalDAV、兼容 Exchange ActiveSync 的只读同步。
- 全天、跨天与重复日程，多个来源合并与去重。

## AI 账户额度

- Codex、Claude、Kimi、Grok Bot、Gemini、ZCode、WorkBuddy、DeepSeek。
- 按服务提供的字段显示订阅额度、重置时间、套餐积分或 API 余额。
- 多账号命名、颜色与常驻显示；Claude 仅使用本机历史 / 缓存或官方状态栏输出，不通过 Claude 登录令牌请求额度接口。

## 账户与设置备份

- 设置侧栏新增「账户」：使用有 Gists 读写权限的 GitHub 个人访问令牌连接自己的账户。
- 手动备份外观、页面布局、时钟、歌词、专注和饮水偏好；重新连接同一账户可发现已有备份。
- 恢复前显示确认，并将当前设置保存为本地副本；本机路径、权限设置和各业务账户保持独立。
- 登录令牌保存在 Windows 凭据管理器，不上传密码、令牌、邮件、日历或剪贴板。
- 使用非公开 Gist 保存偏好，拥有链接的人仍可查看；断开连接保留本机设置和云端备份。
- 微信、QQ 当前显示「待接入」，尚不支持这两种登录方式。详见 [账户使用说明](ACCOUNT.md)。

## 更新与数据

- 关于页直接检查 [本仓库正式版](https://github.com/Snowflake006/Windows-Island/releases/latest)。
- 发现新版后点击「立即更新」：后台下载、显示进度、可取消，校验下载大小与 SHA-256 后替换当前 exe、重启。
- 安装脚本验证包内唯一程序、版本和缓存路径；校验失败不替换现有程序；保留设置与用户记录。
- 原有 `%APPDATA%\Daozai` 数据兼容，邮箱等凭据沿用 Windows 凭据管理器 / DPAPI；内置便携 Python，无需用户单独安装。

## 使用范围

智能体是否能读取到细节取决于对应客户端与本机日志；隐藏窗口的 UI 控件可能不更新。VPN 延迟是当前节点的单点测量，不代表所有分流网站。日历、邮箱和额度取决于授权与服务兼容性；歌词依赖元数据与来源。电脑关机、睡眠或程序退出期间无法持续提醒。Windows 10 / 11 x64 为发布目标。
