# 账户与设置备份

打开「设置 → 账户」，位于 AI 额度下方、关于上方。

1. 点击「在 GitHub 创建访问令牌」，登录自己的 GitHub。创建经典个人访问令牌时勾选 `gist`，或给细粒度令牌授予 Gists 读写权限。不要将令牌发送给他人。
2. 将令牌粘贴到账户页并点击「连接 GitHub」。令牌仅保存在 Windows 凭据管理器。
3. 点击「备份当前设置」保存当前偏好。程序仅在点击备份时上传，不会自动同步。
4. 点击「恢复云端设置」，核对备份时间后确认恢复。恢复前的本机副本保存在数据目录的 `settings.before-account-restore.txt`。
5. 「断开连接」仅删除本机登录凭据，保留当前设置和云端备份。如需撤销令牌或删除备份，请在 GitHub 中操作。

备份包括外观、页面布局、时钟、歌词、专注和饮水偏好，不包括密码、令牌、邮件、日历、剪贴板或本地文件路径。备份保存在非公开 Gist，拥有链接的人仍可查看，历史版本由 GitHub 保留。更换电脑后连接同一个 GitHub 账户即可发现已有备份。
