# 账户功能本地测试

此启动器用于本地隔离测试，不上传测试数据或登录凭据。

1. 先从系统托盘退出当前运行的 Windows Island，再打开测试目录中的「打开账户设置.cmd」，进入设置 → 账户（AI 额度下方、关于上方）。
2. 点击「在 GitHub 创建访问令牌」，登录自己的 GitHub，创建具有 `gist` 权限的经典访问令牌；也可使用授予 Gists 读写权限的细粒度令牌。不要将令牌发送到聊天或提交进代码。
3. 将令牌粘贴到账户页，点击「连接 GitHub」，看到自己的用户名后点击「备份当前设置」。
4. 修改皮肤或专注时长，再点击「恢复云端设置」。核对备份时间后确认恢复，检查设置是否还原。
5. 重启测试程序，检查账户仍可使用。断开连接后，本机设置和云端 Gist 应保留；重新连接同一个 GitHub 账户应找到原备份。

设置备份采用非公开 Gist，仅手动上传，链接知情者仍可访问。密码、令牌、邮件、日历、剪贴板、本地路径不参与备份。恢复前的本地副本位于当前数据目录的 `settings.before-account-restore.txt`。

测试启动器使用测试目录下独立的 `data` 文件夹，从默认偏好开始，不修改已安装版本的设置，也不复制现有账号或登录凭据。请勿将 `data` 文件夹公开分享。请始终通过启动器运行，以保持测试数据隔离。

微信和 QQ 按本次确认显示「待接入」；仍需后续申请开放平台应用和授权服务。没有使用真实 GitHub 凭据的自动测试不会向外部账户创建或修改 Gist，首次真实连接与云端往返需由用户验证。
